# Flow Studio

## Windows Electron 앱

[최신 릴리스](https://github.com/nazana/flow-drawio/releases/latest)의 Windows 포터블 EXE를 더블클릭하면 앱 창이 열립니다. 데이터는 EXE 옆 `.data`에 저장됩니다. [실행·업데이트 안내](docs/electron-release.md).

Windows에서 `npm ci` 후 `npm run electron:portable`로 빌드할 수 있습니다. 개발 실행은 `npm run electron:start`입니다.

## 기존 브라우저 포터블 다운로드

[GitHub 릴리스](https://github.com/nazana/flow-drawio/releases/tag/v0.1.0)에서 운영체제별 ZIP을 받으세요. Node.js 설치나 npm 설치 없이 실행할 수 있습니다. [포터블 실행 안내](docs/portable.md).

소스에서 포터블 패키지를 만들려면 `npm ci`, `npm test`, `npm run build` 후 `python3 scripts/package-portable.py`를 실행합니다. 공식 Node.js 런타임 다운로드에 인터넷이 필요하며 SHA256을 검증합니다. 결과는 `releases/`에 생성됩니다. 특정 플랫폼만 만들려면 `python3 scripts/package-portable.py win-x64`처럼 지정하세요.

회사 내부망에서 실행하는 draw.io 기반 시스템·인터페이스 편집기. Docker와 Next.js 없이 React UI, 로컬 draw.io, Node.js API와 SQLite를 한 프로세스에서 제공합니다.

## 실행

Node.js 22.13 이상. 프로젝트 폴더에서 실행합니다.

```sh
npm ci
npm run build
npm start
```

브라우저: **http://127.0.0.1:5180/**. `index.html`을 파일로 직접 열면 동작하지 않습니다. 현재 실행 환경에서 설치·빌드·실행을 완료했습니다.

```sh
# 개발 모드 (운영 서버를 먼저 중지한 뒤 실행)
npm run dev
# 저장 및 XML 검증
npm test
```

포트는 `PORT`, 주소는 `HOST`, DB 경로는 `FLOW_DB_PATH`로 지정합니다. 기본 DB는 `.data/flow.sqlite`입니다. DB 백업은 서버를 중지한 상태에서 `.data` 디렉터리 전체를 복사하세요. 운영 서버는 `npm start`이며 Vite 개발 서버를 배포하지 않습니다.

## 사용

1. **＋ 새 문서**에서 업무 흐름·시스템 연계·시퀀스·시스템 구성·상태 전이·데이터 모델의 샘플을 고릅니다. 미리보기와 제목을 확인하고 **이 초안으로 시작**을 누르면 개별 요소를 편집할 수 있는 새 문서가 생성됩니다. **＋ 빈 문서**도 사용할 수 있습니다. 문서가 없는 첫 실행에서는 갤러리가 열리며 자동 샘플 문서는 생성하지 않습니다. 시스템 연계·시퀀스는 시스템/I/F 예시와 I/F 목록을 포함합니다. 상단 **I/F 목록**으로 언제든 표시·숨김을 바꿀 수 있습니다. 미저장 변경이 있으면 저장·버리기·취소를 선택합니다.
   샘플 그림과 미리보기는 로컬에 포함됩니다. 시퀀스는 draw.io 기본 생명선과 메시지로 구성하며 자동 순서 재배치는 지원하지 않습니다. 갤러리에서 Esc로 닫고 Tab·Enter·Space로 조작할 수 있습니다.
2. 오른쪽 **시스템**, **I/F** 탭에서 정의를 추가·수정합니다.
3. 도형이나 연결선을 선택하고 **선택 속성**에서 시스템/I/F를 지정한 뒤 **속성 적용**을 누릅니다. 선의 **새 I/F 만들기**는 정의 생성과 선 지정을 한 번에 처리합니다. 노드 소속이 없어도 송수신을 직접 선택할 수 있으며, **송수신 정보를 도형의 소속에도 적용**을 선택했을 때만 노드 소속을 바꿉니다.
   상단 **보기 → 노드 시스템명 표시**는 업무 이름 아래 소속을 표시합니다. 표시 설정은 그림과 함께 저장되고 실행 취소도 가능합니다. 이 시스템명 표시는 Flow Studio 전용이며 원래 업무 이름은 바꾸지 않습니다.
4. 상단 **저장**으로 그림과 정의를 함께 저장합니다. 문서 선택으로 다시 열 수 있습니다.
5. **.drawio 다운로드**는 그림과 정의가 들어 있는 파일을 만듭니다. **파일 열기**는 새 문서로 가져옵니다.

코드는 생성 후 고정합니다. 사용 중인 정의를 삭제하려면 먼저 그림에서 지정을 해제해야 합니다. 송·수신 불일치 등 작성 중인 문제는 패널에서 경고하며 저장은 허용합니다. 별도 창에서 저장한 최신 내용을 오래된 창이 덮어쓰려 하면 충돌 오류를 표시합니다.

## 구성과 설계 재검토

[설계·검증 기록](docs/review.md), [편집 가능한 구성도](flow-architecture.drawio).

- `src/App.tsx`: 문서·속성 패널, 저장 UI
- `public/flow-bridge.js`: draw.io 선택 이벤트, 메타데이터 변경, 전체 XML 스냅샷
- `src/model.ts`: 시스템·I/F 검증
- `server/xml.ts`: XML 검사 및 정의 추출
- `server/db.ts`: SQLite 트랜잭션과 revision 충돌 검사
- `server/index.ts`: 정적 파일·API·외부 리소스 차단 정책

## 폐쇄망 반입

`public/drawio`에 draw.io **v31.4.6** 정적 앱과 라이선스를 포함했습니다. `npm run build`가 이를 `dist/drawio`에 복사합니다. 외부 CDN을 사용하지 않습니다.

인터넷 가능한 준비 환경에서 `npm ci`와 빌드를 마친 뒤 `dist`, `server`, `src/model.ts`, `src/sample.ts`, `public/flow-styles.js`, `package.json`, `package-lock.json`, `node_modules`를 대상 서버로 반입합니다. 대상 OS/아키텍처에 맞는 Node.js도 준비해야 합니다. `.data`는 서버 시작 시 생성됩니다. 폐쇄망에서 npm 레지스트리에 연결해 설치할 필요가 없도록 의존성도 함께 반입하세요.

운영 서버의 CSP가 외부 스크립트·이미지·폰트·fetch·iframe 리소스를 차단합니다. 외부 이미지 URL, 외부 웹 폰트, 클라우드 저장처럼 인터넷이 필요한 draw.io 기능은 지원 범위 밖입니다. 브라우저에서 외부 연결을 제한한 상태의 기본 편집·저장·재조회는 확인했으며, 물리적으로 네트워크를 분리한 대상 사내 서버 검증은 별도로 필요합니다.

## 현재 범위

로컬 사용이 가능한 시제품입니다. 로그인·권한·감사 이력·동시 공동편집은 아직 없습니다. 기본 바인딩은 `127.0.0.1`입니다. 여러 사용자가 접속하는 사내 서비스로 배포할 때는 인증과 접근 권한을 먼저 추가해야 합니다.


## I/F 표현과 자동 범례 (3-1)

- 상단 **표현·범례 설정**에서 문서별 TC/EVENT/API의 범례 이름·선 모양·색·두께·시작/끝 표시를 설정합니다. 이중선은 화살표 없이 사용합니다.
- 새로 I/F를 지정한 일반 선은 설정을 따릅니다. 기존 I/F 선은 모양을 보존하며, 선택 속성의 **선 표현 → 문서 설정 따르기**로 참여시킬 수 있습니다.
- 직접 색·두께·선 모양·화살표를 바꾸면 **개별 모양 유지**로 판정합니다. 이후 문서 설정을 바꿔도 덮어쓰지 않습니다. 경로·위치·라벨 변경은 이 판정에 영향을 주지 않습니다.
- **범례 넣기**는 현재 페이지에 하나의 범례를 넣거나 기존 범례를 선택합니다. 현재 페이지에서 사용 중인 모든 I/F 종류를 표시합니다.
- 범례는 draw.io 도형처럼 이동·크기 조절·삭제할 수 있습니다. 내용은 자동 관리되며 배치는 갱신 시 유지합니다. 설정 변경과 선·범례 갱신은 실행 취소 한 번으로 복원됩니다.
- **저장**하면 설정과 범례가 그림 XML에 포함됩니다. 범례에는 마지막 생성 내용도 저장합니다. 일반 draw.io에서는 저장된 범례를 볼 수 있지만 자동 갱신은 Flow Studio에서 동작합니다.
- PNG/SVG/PPTX 출력 전체 검증은 13번에 남아 있습니다.

## 선택한 요소로 만드는 범례

- 스크래치 패드는 그대로 사용합니다. 별도의 내 요소 팔레트는 제거했습니다.
- 도형·선을 선택하면 오른쪽 선택 속성 상단에서 이름을 입력하고 `범례 설정에 추가`할 수 있습니다.
- `범례 넣기`는 현재 페이지에서 지정한 요소의 실제 모양·색을 표시합니다. 원본을 수정하면 범례도 따라갑니다. 동일한 이름·스타일·크기는 한 번만 표시합니다.
- `표현·범례 설정`의 `추가한 범례`에서 이름·원본 바탕색·선 색을 수정하거나 등록을 해제할 수 있습니다. 원본 색 변경은 캔버스 요소에도 적용됩니다. 도형 구조는 `원본 선택 · 모양 수정`으로 이동해 draw.io에서 편집합니다.
- 설정창의 `I/F 선 스타일`은 선 스타일만 관리합니다. 현재 페이지에서 사용하는 I/F 종류는 개별 모양 여부와 무관하게 자동으로 범례에 표시합니다. I/F 범례는 종류별 설정의 대표 스타일을 사용합니다.
- 기존 내 요소로 지정했던 도형은 범례 이름과 포함 상태를 이어받습니다. 새 팔레트나 템플릿을 만들지 않습니다.

## 기본 스타일 패널과 재연결

- 범례 설정의 원본 편집 버튼은 원본 도형·선을 선택하고 draw.io 스타일 패널을 엽니다.
- I/F 선택 속성에서 **이 선 스타일 편집** 후, 필요하면 **현재 스타일을 같은 I/F 종류에 적용**합니다. 같은 종류 중 문서 설정을 따르는 선과 자동 범례에 반영됩니다. 개별 모양을 유지하는 다른 선은 보존합니다.
- 연결된 시스템과 I/F 송수신이 다르거나 끝이 끊기면 비교 선택창을 표시합니다. I/F를 노드 시스템에 맞추기, 노드를 I/F 시스템에 맞추기, 이 선의 I/F 지정 해제 중 선택합니다. 공유 정의와 노드 변경의 영향 건수를 표시합니다.
- 시스템 미지정 노드도 비교 선택창에서 안내합니다. 사용자가 결정하기 전까지 I/F를 유지합니다. ESC/나중에는 변경하지 않으며 연결 정보 확인 버튼으로 다시 열 수 있습니다. 선택한 동기화/해제는 한 번의 실행 취소로 복원하고, 재연결은 그 이전 편집으로 남습니다.

## 1분 자동저장과 복구

- 편집 중인 문서 제목과 그림 XML을 1분마다 SQLite의 별도 복구본으로 저장합니다. 수동 저장본과 문서 revision은 바꾸지 않습니다.
- 탭별 복구본을 분리합니다. 문서를 다시 열면 저장 시각별로 복구본을 선택할 수 있고, 선택하지 않은 복구본도 유지합니다.
- 복원은 편집기에만 적용됩니다. 확인 후 저장해야 수동 저장본을 대체합니다. 오래된 revision의 복구본에는 안내를 표시합니다.
- 수동 저장 성공 시 현재 탭 복구본과 복원에 사용한 해당 시점의 복구본을 정리합니다. 다른 탭이 그 뒤 갱신한 복구본은 남깁니다.
- 다른 탭에서 수동 저장하여 revision이 달라지면 자동저장은 덮어쓰지 않고 실패 이유를 표시합니다.
- 서버에 저장되기 전 최대 1분의 변경, 아직 편집기에 적용하지 않은 입력은 복구되지 않을 수 있습니다. 창 닫기 전 수동 저장을 권장합니다.

## 버전 이력과 변경 메모

- **저장**할 때마다 제목·그림·속성의 전체 스냅샷을 버전으로 남깁니다. **메모와 저장**에서는 변경 메모(최대 500자)를 함께 기록합니다.
- **버전 이력**에서 저장 시각·메모를 확인하고 과거 버전을 복원합니다. 복원은 새 버전으로 저장되므로 이전 이력은 유지됩니다. 미저장 편집 내용이 있으면 대체 여부를 확인합니다.
- 이력 기능 도입 전 문서는 현재 저장본부터 이력을 시작합니다. 이미 덮어쓴 과거 내용은 생성하지 않습니다.
- 자동 복구본은 버전 이력과 별도이며, 버전 복원에도 revision 충돌 검사를 적용합니다.

## 문서 목록·태그·상태

- 상단 **문서 목록**에서 제목·설명·태그를 검색하고 상태/태그 필터를 조합합니다. 최신 저장 순으로 표시합니다.
- **문서 정보**에서 설명(2,000자), 여러 태그(각 40자, 최대 20개), 상태(작성 중/검토 중/완료)를 편집합니다. 적용 후 저장하면 반영됩니다.
- 태그는 기존 문서의 값을 추천하고 앞뒤 공백·중복을 정리합니다. 특정 문서에서 태그를 제거해도 다른 문서에는 영향이 없습니다. 대소문자는 구분합니다.
- 문서 정보는 자동 복구본과 버전 이력에도 포함됩니다. 기존 문서는 빈 설명·태그와 작성 중 상태로 시작합니다.

## 문서·페이지 링크

- 도형·선을 선택하고 오른쪽 **문서·페이지 링크**에서 다른 저장 문서 또는 현재 문서의 다른 페이지를 선택합니다. **링크 적용** 후 그림과 함께 저장합니다.
- 캔버스에서 선택 시 나타나는 기본 링크 또는 오른쪽 **↗ 열기**로 이동합니다. 페이지 링크는 draw.io 기본 페이지 링크 형식을 사용합니다.
- 문서 이동 시 미저장 변경이 있으면 취소 / 저장 없이 열기 / 저장 후 열기를 선택합니다. 없는 문서·페이지는 오류로 안내하며 현재 내용을 유지합니다.
- 링크는 해당 요소의 기본 링크 하나를 사용합니다. 외부 링크가 있는 경우 적용하면 교체됩니다. 해제는 링크만 제거합니다.
- 문서 링크는 이 앱의 저장소 ID를 참조합니다. 다른 저장소나 일반 draw.io에서는 문서 열기가 지원되지 않습니다. 현재 범위는 문서 이동이며 버전/특정 노드 이동이나 그림 병합은 포함하지 않습니다.
