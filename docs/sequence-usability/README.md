## 사용성 개선 후보

1. 전체 보기가 가로 폭을 맞추면서 마지막 전문이 세로 화면 밖으로 나갈 수 있다. 가로·세로를 함께 고려하는 전체 보기 필요.
2. 긴 시퀀스에서 아래로 이동하면 시스템 이름이 화면 밖으로 사라진다. 참여자 이름 고정 표시 또는 위치 안내 방식 검토.
3. 전문 수가 많을 때 I/F 목록의 검색·연결선 찾기·강조와 캔버스 이동이 편집 흐름을 얼마나 줄이는지 사용자 테스트.
