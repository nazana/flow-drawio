# 같은 네트워크에서 실시간 보기 공유

Flow Studio를 실행한 노트북이 공유 서버입니다. 발표자는 노트북의 `http://127.0.0.1:5180/` 또는 Electron 앱에서 편집하고, 다른 PC는 같은 사내망·Wi-Fi에서 공유 링크로 접속합니다. 별도 계정 로그인은 필요 없습니다.

1. 문서를 열고 **실시간 보기 공유**를 누릅니다.
2. **공유 비밀번호**를 직접 입력하고 **공유 시작**을 누릅니다. 비밀번호는 8~128자이며 이번 공유에만 사용합니다.
3. **링크 복사**와 **비밀번호 복사**로 접속 정보를 전달합니다. 여러 주소가 표시되면 상대방과 같은 네트워크에 연결된 주소를 선택합니다.
4. 상대방은 브라우저에서 링크를 열고 비밀번호를 입력합니다. 문서의 변경 내용이 저장 전에 반영되며, 발표자가 페이지를 바꾸면 같은 페이지를 표시합니다.
5. **● 공유 중 → 공유 중단**으로 접속을 종료합니다. 비밀번호를 바꾸려면 중단 후 다시 공유하세요.

도형·선·속성·제목 변경은 즉시 공유합니다. 도형 안의 텍스트를 입력 중이라면 입력을 확정했을 때 반영됩니다. 변경된 그림을 다시 읽기 때문에 아주 큰 문서는 갱신에 시간이 걸릴 수 있습니다. 발표자의 마우스 위치나 확대율은 전송하지 않습니다. 현재 문서의 모든 페이지가 포함되므로 공개해도 되는 문서만 공유하세요.

다른 PC에는 보기 화면만 제공하며 문서 목록·저장·수정은 서버 노트북의 localhost에서만 가능합니다. 서버에는 비밀번호 원문을 저장하지 않고 해시만 메모리에 보관합니다. 저장된 문서·자동복구·버전 이력은 기존 SQLite 저장소를 사용하며 실시간 공유 내용은 수동 저장본을 덮어쓰지 않습니다.

문서를 바꾸거나 공유를 중단하면 기존 링크가 만료됩니다. 창을 닫거나 서버가 재시작되면 다시 공유해야 합니다. 발표자와 서버의 연결이 끊기면 약 45~55초 후 공유가 만료됩니다. 절전 모드에서는 접속할 수 없습니다.

운영 서버는 LAN에서도 접속 가능한 주소에 바인딩됩니다. 방화벽에서는 Flow Studio를 사설 네트워크에만 허용하세요. 브라우저 버전은 기본 5180 포트를 사용합니다. Electron은 사용할 수 있는 포트를 자동으로 선택하며 공유 링크에 포함합니다. 개발 서버(`npm run dev`)는 localhost 전용이므로 LAN 공유 검증은 빌드 후 `npm start`로 하세요.

이 버전은 신뢰하는 같은 사내망에서 사용하는 HTTP 공유입니다. 네트워크 구간의 암호화는 제공하지 않으므로 다른 서비스에서 쓰는 비밀번호를 재사용하지 마세요. 인터넷 포트 개방·외부 공개는 지원 범위에 포함하지 않습니다. 사용자별 로그인과 공동편집은 아직 없습니다.
