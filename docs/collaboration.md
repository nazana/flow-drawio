# 노트북 서버에서 함께 캔버스 수정하기

같은 사내망·Wi-Fi에서 여러 PC가 같은 문서를 수정할 수 있습니다. 서버 노트북은 Flow Studio를 실행한 상태로 두세요. 개별 계정 대신 이번 공유에 설정한 공통 비밀번호를 사용합니다.

1. 노트북에서 문서를 열고 **실시간 공유**를 누릅니다.
2. **공유 권한 → 공동편집 · 함께 수정**을 선택하고 비밀번호를 직접 입력합니다.
3. **공유 시작** 후 링크와 비밀번호를 각각 복사해 전달합니다.
4. 참여자는 링크를 열고 비밀번호를 입력하면 도형·연결선·글자·배치·제목을 수정할 수 있습니다. 각 참여자는 자기 확대율과 페이지를 선택합니다.
5. 노트북의 **저장**을 눌러 공동편집 결과를 문서와 버전 이력에 남깁니다. 참여자의 캔버스 수정은 실시간으로 전달되지만 문서 저장·공유 종료·다른 저장 문서 조회는 서버 노트북에서만 가능합니다.

**보기 전용**을 선택하면 기존처럼 수정이 차단됩니다. 공유 중에는 권한·비밀번호를 바꿀 수 없으며, 중단 후 새로 공유해야 합니다. 문서를 바꾸거나 노트북 앱을 종료하면 공유도 종료됩니다.

서로 다른 도형 또는 서로 다른 XML 속성의 변경을 합칩니다. 같은 속성을 동시에 바꾸면 서버에 나중에 도착한 변경이 반영됩니다. 삭제된 도형은 동시 수정 때문에 다시 생기지 않습니다. 같은 도형의 선 색·글꼴처럼 하나의 스타일에 들어 있는 설정을 동시에 바꾸면 마지막 스타일이 반영됩니다.

글자 입력과 드래그는 동작을 확정했을 때 전달됩니다. 다른 사람의 변경은 현재 글자 입력 또는 드래그가 끝난 뒤 적용하므로 진행 중인 입력을 끊지 않습니다. 도형을 추가하면 참여자별 고유 ID를 사용합니다. 네트워크 재시도는 같은 편집을 중복 적용하지 않습니다.

연결이 잠시 끊기면 현재 변경을 보존하고 재연결을 시도합니다. 공유가 종료되거나 비밀번호 세션이 만료되면 다시 접속해야 합니다. 참여자 화면의 **내 변경 내려받기**로 현재 내용을 `.drawio` 파일로 보관할 수 있습니다. 서버 재시작 전에는 노트북에서 저장하거나 각자 변경 내용을 내려받으세요.

현재는 신뢰하는 같은 사내망에서 사용하는 HTTP 공유입니다. 네트워크 암호화와 사용자별 로그인·수정자 이력·커서 표시·사람별 잠금은 포함하지 않습니다. 아주 큰 문서는 XML 전송과 병합으로 갱신이 느려질 수 있습니다. 다른 서비스의 비밀번호를 재사용하지 마세요.
